# Contributing

This repository publishes tested releases of ableton_live_mcp. Development happens elsewhere, so pull
requests aren't accepted here.

Bug reports and feature ideas are welcome as [issues](https://github.com/cmdiego/ableton_live_mcp/issues).
What to include is in the README:
- [Reporting an issue](README.md#reporting-an-issue)
- [Asking for a new feature](README.md#asking-for-a-new-feature)
